# 20261120-R3 后端源码合并说明

## 范围

本包追加在已发送的20261120-R2之后，包含Common、QuoteSvr、NotificationSvr、CRMSvr源码、逐模块补丁、测试及证据。无客户端源码，不改BaseSvr、ParserSvr、QtIntakeSvr或BondSearch Core。R2的交易日/结算日修复仍有效，Parser沿用R2。

| 改动 | 最终行为 |
|---|---|
| 提醒共享分组 | 使用Quote同步的共享关注券/筛选组；支持查询、视图、修改及删除事件 |
| 取消独立提醒分组 | Notification启动自动删除自己配置schema中的notification_settings，不迁移旧NFG分组 |
| CRM机构简称 | 根据有效机构ID取CRM简称；空简称用全称。自动匹配、手工创建、确认、修改使用同一规则 |
| CRM候选优先级 | 完整匹配→前缀→包含；同级短名称优先，再按名称/ID稳定排序，先排序后分页；数据库直查和CRMSvr目录均修改 |
| 依赖一致性 | CRMSvr显式依赖Common 0.1.1-SNAPSHOT，与Quote/Notification对齐 |

自动识别仍要求唯一候选，不因列表第一项排序靠前就自动认定；未匹配的原始名称保持原值。CRM目录仍分别返回institutionName全称和institutionShortName简称；报价institutionName采用简称。没有批量重写旧历史记录。

## 合并与构建

1. Common/Quote补丁基线是20261120-R2实际交付；Notification是20261119-R4实际交付。对应基线源码与旧ZIP逐文件核对，补丁试应用后与本包sources一致。
2. **CRMSvr没有找到可核对的既往邮件源码包**。其补丁采用本机此次修改前提交，manifest明确标记，不能当作已确认的QA基线。仅涉及CrmDirectory、对应测试及pom依赖版本；先git apply --check，遇冲突按这三处差异合并，不强行覆盖QA其他改动。完整源码仅供比对。
3. 先安装Common 0.1.1-SNAPSHOT，再构建QuoteSvr、NotificationSvr、CRMSvr。按现有Jenkins/Salt流程生成配置和服务包，无需复制example或新增连接参数。
4. **Common和Notification必须配套部署**。不要把删除独立分组表的新Common装给旧Notification。停止相关服务后协调部署，避免新旧版本混跑；启动Quote，再启动Notification并确认SOURCE_SYNC READY。CRMSvr部署其Maven构建生成的完整依赖，运行目录不得同时留旧Common 0.1.0与新0.1.1。
5. 本轮未统一db.schema：交付原配置仍Quote后缀3、Notification后缀2。分组走服务间同步，不直接跨schema读表；勿自行切库或搬表。Notification删除范围仅自身schema的notification_settings，无CASCADE，保留共享settings、提醒、偏好和已读。
