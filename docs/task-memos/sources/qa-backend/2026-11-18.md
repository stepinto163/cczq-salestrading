- 原因：旧链路保留QT原始sourceTime但不比较日期；QuoteSvr把收到的旧消息按当前createTime建成今日草稿，日终撤价无法阻止这种迟到创建。用户批准按原发送日拒绝，并让转发队列继续处理。
- 最终处理：QuoteDayPolicy按quote.endOfDay.zone解析FIX tag 60的本地时间，兼容显式时区ISO时间；原日期早于当前营业时区日期或时间格式无效时返回1001/VALIDATION_FAILED/sourceTime。判断位于IntakeCreateEndpoint的路由、来源落库和create/update之前；中文错误及WARN含请求、券码与原时间。QT Intake将该字段的明确校验失败归入既有rejected档案并释放队首，不将网络/权限/归属失败当成丢弃。无新请求字段、数据库表或前端改动；不增加同日乱序或未来日期拒绝规则。
