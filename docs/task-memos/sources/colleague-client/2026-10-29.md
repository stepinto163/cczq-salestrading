# 同事客户端适配修复

- 范围：仅本 `stc-client` 仓库，分支 `dev_sales_trading_backend`。未合并至 FICC 集成分支，未修改服务端。
- 基础资料：增强 `STC.Common` 与 `STC.Data.Plugin`，使用 FiccBaseSvr 完整快照及版本增量，环境隔离的 SQLite 缓存；报价、行情、提醒读取共享内存。增量删除及估值变化同步更新已显示行，不再按报价调用 `ficc.base.get`。CRM 机构/联系人搜索仍使用原接口。
- 关注债券识别：支持完整代码、裸代码、大小写及首尾空格，返回规范代码。多市场重码要求完整代码，不猜市场。
- 行情全部：信用/利率 FULL 请求增加 `rowShape=QUOTE`，按 quoteId、服务端顺序及总数分页；保留同券多笔报价，处理实时替换和空结果，不再展开价格簿后二次分页。
- 显示字段：填充简称、期限、IBOR 债券库、主体/债项评级、中债/中证估值；中证全价有源值才显示。报价归属显示名从宿主用户缓存补充。识别 Bid 在创建前也显示方向。
- 中债偏离：保留原有买卖方向口径。收益率差乘 100 为 BP；净价与中债净价相减为价格差；Ofr 取反。收益率基准不一致、全价缺少可比估值或源值缺失时留空，不伪造数据。
- 精确确认根因：旧逻辑先创建所有行，再静默跳过部分 CRM 未匹配行，而页面仍当作全部成功移除。现在创建前校验 CRM，逐项处理回执，页面只移除成功 ACTIVE 行，失败行保留并可重试。通信结果未知时复用原 requestId；确认失败重试不重复创建。切换计价方式同步 yieldType，清空价格/数量不再沿用旧值。
- 构建：修正 Common 的 RocksDB、Frame 的 Ats.Foundation 引用为仓库已有 `client/bin` 文件；修正销售交易插件在 `STC.sln` 中的 `Any CPU` 平台映射，避免 VS 跳过构建。NuGet restore 可消除复制来的旧机器绝对路径资产。


脚本恢复依赖、构建到临时目录并执行回归；不安装到运行中的客户端。完整交付需共同构建 `STC.Common`、`STC.Data.Plugin`、`STC.SalesTrading.Plugin`，以及带 `Ficc.BaseService=FiccBaseSvr` 的 STC 配置，不能只替换销售交易 DLL。
