# V1.8.3：FICC Python 3 无界面功能测试源码候选

前序交付为V1.8.2（NCD及Jenkins旧JAR清理）。本包新增测试工具，不修改或替换BaseSvr、QuoteSvr、NotificationSvr、ParserSvr或同事客户端源码，不需要重新部署业务服务。请合并到主工程的`iteration1/headless-tests`，使用QA真实连接参数运行。

本次是可运行的首版套件，**尚未覆盖全部业务场景，不是应用全场景验收通过版本**。测试缺口逐项保留，不能将PASS数量当成业务覆盖率。

## 使用方法

详见包内`iteration1/headless-tests/README.md`。Python3负责所有业务断言；独立C#控制台适配现有Gateway SDK，不启动STP。Windows构建桥接时，用`build-bridge.ps1 -SdkDirectory <现有SDK目录>`指定包含gateway-api.dll的目录。无需合并或改动同事客户端。

填写本机/QA配置中的网关地址、两名测试用户、DM只读连接及Quote业务库只读连接。业务库schema必须与QuoteSvr一致。默认不允许业务写入，专用测试环境确认后设置JSON布尔值`allowWrites=true`；报价与分组写入均经过真实接口，不向DM造模拟债券。

先运行read-only，再运行smoke；functional按样本覆盖完整的已实现字段矩阵。套件串行执行，有SQL超时、报价数量限制、进程看门狗和清理台账，不是压力测试。QT外部FIX保持停止。

## 需要QA结合当前修复确认的差异

1. **含权**：20261021字典明确embedded_option=0含权、1不含权、2永续。本机现有Base/Core仍反向，真实资料及筛选断言失败。QA已在修复，不在本包重新修改产品。2及缺失码的布尔口径未确认时用例阻塞。
2. **企业性质**：字典定义business_filter_nature=999其他，本机映射仍为4/5其他；包含相应真实样本时出现差异。请核对QA源数据与映射，不直接修改测试预期让其通过。
3. 剩余期限使用FICC当前日与到期日的合同，不能把DM快照remaining_tenor_day直接当期望；本机纠正预期后该组通过。
