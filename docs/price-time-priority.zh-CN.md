# 行情价格与时间优先：核查和修正

日期：2026-10-16。范围：行情中心主表、最优价展开明细；用户明确限定同一债券、同一方向。

## 规则

1. 先比较统一收益率：Bid 由低到高，Ofr 由高到低。价格不同，不因报价更新较晚而越过更优价格。
2. 同价时按更新时间实际时刻倒序，最新报价优先；相同时刻按 quoteId 升序。
3. 普通债采用到期收益率，含权债采用行权收益率。净价等不同输入口径由 QuoteSvr 调用 CalSvr 转成目标收益率后参与排序；不把净价 100 与收益率 2 当同一单位比较。
4. 原始报价价格和类型不因行情投影而改变。换算未完成或失败的条目暂不参与排序，通过 calculationIssues 提示部分数据；其他报价正常显示。
5. 不同债券组仍按最新更新时间组织。本次不调整跨债券排序，也不修改右侧宿主市场深度面板。

## 实际发现和修改

主表和展开明细原本已保留 QuoteSvr 的价格优先顺序，没有发现客户端反转该顺序。
问题在同价比较：QuoteSvr 原先直接比较 ISO 时间文本。比如 `08:00:00+08:00` 与
`00:00:00.001Z`，后者实际更晚，字符串排序却相反。

改为解析 Instant 后比较，同时修正整本价格簿最新时间选择；输出无偏移的档位日期/时间统一到上海时区。
客户端主表 tooltip 原称使用久期近似换算，与真实调用 CalSvr 的实现不符，已改为说明统一收益率比较和原始报价查看位置。
