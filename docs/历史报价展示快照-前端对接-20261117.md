# 历史报价展示快照：前端对接说明（2026-11-17）

## 规则

- 接口仍为 `ficc.quote.history.search`，请求、过滤字段、分页及排序不变。
- `rows[].quote` 是该条历史报价；`rows[].reference` 是随报价保存的当时资料，用于名称、评级、估值、剩余期限和导出。
- 债券/估值筛选仍走已有当前资料/搜索快照；报价自身条件仍匹配历史报价。当前搜索快照按现有机制刷新，并非实时查询DM。
- 同券不同报价/日期可以有不同资料，必须按行取值，不能按 securityId 合并成一份资料，也不能用当前缓存填补历史空值。

## 示例（省略无关字段）

当前评级是AA+，历史报价时评级是AAA。请求筛选AA+，响应仍展示AAA：

```json
{"filter":{"conditions":[{"field":"bondRating","operator":"IN","value":["AA+"]}]},"fromDate":"2026-11-17","toDate":"2026-11-17","pageNumber":1,"pageSize":50}
```

```json
{"rows":[{"tradeDate":"2026-11-17","quote":{"quoteId":"Q-example","securityId":"242480004.IB","price":"2.431"},"reference":{"securityName":"24华夏银行永续债01","issuerRating":"AAA","bondRating":"AAA","valuationYield":"1.7040","valuationCleanPrice":"102.1068","optionType":"ETS","optionDate":"2029-06-11","maturityDate":"2029-06-11","remainingYears":"2.5643835616438357","showTenor":"2.56Y + N"},"referenceAsOf":"2026-11-17T13:38:00.023+08:00","referenceStatus":"CAPTURED"}]}
```

`remainingYears`、`showTenor` 按该次报价捕获日期计算，仅用于历史展示，不改变当前筛选口径。示例剩余年限为说明格式，实际以服务返回为准。

新增标记：

| 字段 | 含义 |
|---|---|
| referenceAsOf | 报价展示资料捕获时间，不是资料供应方的发布日期 |
| referenceStatus=CAPTURED | 已保存快照；其中个别字段仍可为空 |
| referenceStatus=MISSING_SOURCE | 捕获时没有对应券资料 |
| referenceStatus=NOT_RECORDED | 旧记录没有保存过快照 |

后两种状态 `reference` 为空或不输出，显示空值/“--”，禁止取当前资料伪装成历史值。

## 保存与上线

创建草稿、确认、有效报价修改或Unrefer产生新报价时保存当前资料；撤销、删除、日终/补清理以及同版本异步补价保留原资料。没有增加资料变更追踪表，不改变每日历史表的覆盖规则。

后端Common和QuoteSvr、客户端SalesTrading.Plugin需配套更新：旧客户端仍可能用当前缓存覆盖历史值。沿用quotes.payload、history.payload.after、quote_history_daily.snapshot中的JSON扩展，无DDL迁移、不回填旧记录。本次不改BaseSvr、NotificationSvr或BondSearch。
