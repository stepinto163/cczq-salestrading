## 环境与范围

浏览器端使用的相同 JavaScript 客户端模块，在 Node.js 中通过 `ws://127.0.0.1:18601/gateway` 连接实际运行的 GW、QuoteSvr 和 NotificationSvr；业务存储为本机 PostgreSQL。登录、基础数据使用现有模拟适配器。

两个用户 `trader1`、`trader2`，仅新建两条报价，数量各为 1 万。两条测试报价均在结束时业务删除，操作历史保留。提醒偏好恢复为测试前值。没有压力生成或并发基准测试。
